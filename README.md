# Pokédex

A React app for browsing Pokémon and their abilities, using data from [PokéAPI](https://pokeapi.co/).

## Pages

- `/` – Welcome page
- `/pokemon` – List of all Pokémon, with search and pages
- `/pokemon/:name` – Details for one Pokémon: types, abilities, height, weight and base stats

## Built with

React, React Router, Vite and plain CSS.

## Run it locally

```bash
npm install
npm run dev
```
